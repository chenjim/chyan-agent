## 发现（均已修复，2026-11-15 同日验证）

1. **审批卡片按钮被底部输入区遮挡**（`04-approval-before-fix.png`）：375 宽下，带 diff 的审批单把「批准/拒绝」顶到输入框下方，必须滚动才能点到。
   修复：移动端给 `.msg-list` 预留底部空间，并在渲染/刷新后把窗口滚到末尾（桌面端仍由列表内部滚动）。
   验证：`04-approval-after-fix.png`，量得按钮底边 325px < 输入区顶边 517px，无需手动滚动即可点击。
2. **重复批准显示原始错误**：对已解决的审批再点一次，界面出现红字 `approval aprf… not pending`。
   修复：daemon 对「已解决/不存在」的票返回 **409**（原 400），前端把 404/409 视为已处理并静默刷新。
   验证：双击「批准」后 `#session-error` 为空，任务正常完成。
3. **搜索片段含工具调用原始 JSON**（`…"mode":"write","path":…`）：命中可读性差。
   修复：`GET /api/v1/search` 跳过 `role=tool` 行，只搜用户与助手文本。
4. **PWA 升级后白屏**（复验时新发现）：Service Worker 对 `index.html` 用缓存优先且缓存名固定，
   重新构建后旧 index 指向已不存在的 hash 资源，页面空白。
   修复：导航请求改网络优先（离线回退缓存），hash 资源保持缓存优先；缓存名升到 `chyan-v5`。
   验证：装好 SW 后换一版构建、重启 daemon、单次 reload，页面加载到新 index（探针命中、正文正常）。
